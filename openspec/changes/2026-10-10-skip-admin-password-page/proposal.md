# 已改密后不再弹出改密页

## 为什么

店主密码已经改过，`must_change_password` 为 false。管理登录却一律跳到「修改店主密码」。从重置批准页登录时，人被带离批准按钮，重置也就不会执行。

## 做什么

- 只有 `must_change_password` 仍为 true 时，登录后才进入改密页。
- 已经改过时，若登录来自管理页下的返回地址，回到该地址；否则停在已登录说明，不展示改密表单。
- 人明确要求时仍可改密。改密成功后回到原来的返回地址。

## 不做什么

- 不改商家授权页的改密规则。
- 不让 Agent 代批重置。
- 不根据环境变量重写已保存的密码。
