# Design

## 选择

回滚只恢复脚本自己写下的文件。容器和数据卷一旦创建，就不能靠删除 `.env` 假装没安装过，因为密码只在这个文件里。

第一次安装先把 `compose.yaml` 和 `.env` 写到临时目录，再移入安装目录。移动 `.env` 成功才算提交。提交前的 Ctrl+C 或失败删除临时文件；如果目录是这次新建且已经空了，也删掉目录。提交后保留配置，沿用原来的失败提示。

升级在替换前把 `compose.yaml` 和 `.env` 里的 `MERCLINK_IMAGE`、`MERCLINK_RELEASE_TAG` 复制到仅当前用户可读的临时目录。失败或 Ctrl+C 时复原这两个键和部署文件，并删掉半成品 `compose.yaml.next`。不执行 `compose down`，也不再自动 `up` 旧镜像。已经换成新镜像的容器要由操作者再执行 `docker compose up -d` 才会和还原后的文件一致。

`latest` 仍不是版本回滚点。要退回旧应用镜像，仍须把 `MERCLINK_IMAGE` 改成版本号标签。

## 不做

- 不在提交 `.env` 之后删除密码或数据卷。
- 不把已经运行的新容器自动换回旧镜像。
- 不增加卸载命令，也不改变安装时询问的字段。
