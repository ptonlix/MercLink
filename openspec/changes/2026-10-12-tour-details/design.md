## Decisions
数据仍只有商品记录一份事实。地址与时间作为目录可选 text 字段写入，预约链接复用已有 other_payment；不在页面按商品 ID 硬编码行程信息。第三条没有地址则不展示地址行。首条标题按用户提供的新名称更新并去除尾部 HTML 空格实体。
人数仅为本次购买意图，默认 1、只接受正整数、不超过已选择规格的有限库存。变化后复制反馈重置，购买需求明确人数。无脚本不提供无效加减按钮，直接说明向 Agent 提供人数；不自动预约或下单。
三个商品另有与封面画面相同、URL 不同的相册首图；经页面对照后移除这三条重复引用，保留原图片文件与数据快照。图集按 URL 去重，沿用原生 radio 驱动。每个非当前图片在缩略图网格出现一次，当前图片的缩略图隐藏，保持单张主图与左右切换；无脚本仍可用。图片失败沿用占位。
## Validation
验证三个真实商品的事实、人数上下界及复制原文、缩略图与箭头、移动端；更新相关回归并执行 check 与冒烟覆盖。修改本地数据前保存可恢复快照，不记录凭据。
