# Proposal

## Why

公开店面仍是静态商品架。店主要求首页像流媒体一样自己横滚，列表看全商品，详情展开全部图片和中英文介绍。

## What Changes

- 首页已上架商品改成一条 CSS 影片带，自己横向循环，悬停暂停。减少动态效果时停住，仍可手滑。
- 列表展示封面、英文名和中文名。详情保留分段介绍，支付链接可点，并把 `gallery` 字段里的本站图片排成图集。
- 不新增依赖，不自动播放视频或音频。价格仍由服务端填入。

## Capabilities

### Modified Capabilities

- `public-pages`：首页商品架允许 CSS 自行横移，不再禁止这种非媒体自动播放。

## Impact

- 改公开页模板和样式。商品多图存在已有文本字段 `gallery`，不改表。
