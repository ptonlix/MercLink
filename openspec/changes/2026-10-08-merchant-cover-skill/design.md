# Design

## 为什么这样写

封面看不见，是因为 Skill 把「上传得到的本站 URL」和「任意外部 URL」写成了二选一。规格仍允许外部 URL，所以这次不收紧接口。收紧的是 Agent 说明：外部地址不是上传失败后的替代品。

## 决定

- 正常路径只有一条：`POST /api/v1/catalogs/{id}/images`，再把 `data.url` 写入 `cover`。Agent 不调用 S3 或 MinIO。
- `50301` 和 `42900` 都停止。不写本地文件，也不改这一次的封面。
- 外部地址保留，因为 `product-images` 规格允许。Skill 必须加上匿名可读这个使用条件，并写明上传失败不是使用它的理由。
- 不在写入时让服务器代拉外部地址。那会变成新的网络依赖，也超出这次说明修复。

## 不做什么

- 不拒绝所有外部 `cover`。
- 不改 `GET /media/{id}`、上传限流或对象存储配置。
- 不改买家 Skill。
