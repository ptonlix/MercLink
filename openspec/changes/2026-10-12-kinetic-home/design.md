## Context

本次是用户明确要求的首页方向调整。商品、店铺和公开事实已有服务端入口，默认源码包复用视图但不运行 React。上一版自动影片带将被本次悬停页卡取代。CLI 暂用 kinetic-home，校验后使用日期前缀目录。

## Goals / Non-Goals

**Goals:** 一眼可辨的官网首屏、明显且可控的商品展开动效、整卡直达详情、手机与无脚本回退。

**Non-Goals:** 不重新改列表/详情/授权，不引入动画库、素材下载、推荐、购物车或新业务能力。

## Decisions

1. 首页局部 token 使用冷石墨 #0c1218、冰白 #edf4f7、冰青 #9ee8e0。大字号无衬线品牌字与细线空间框架，复用真实摄影，区别于上一轮暖色衬线影片带。其余页面保持原 token。
2. 商品每三件为一排，整张原生链接可点击。桌面 hover 和 focus-visible 扩大当前列，两侧收拢；每排独立，超过三件继续下一排。不丢商品、不复制商品、不自动切换焦点。静态模板使用自动网格，保留所有商品槽位。
3. 动效节奏：首屏标题与展台一次短入场；页卡展开为主动作；图片跟随指针小幅平移、入口箭头响应。没有持续自动动画。减少动态效果时所有内容保持静态、标题和价格完整可见。
4. CSS 提供无脚本的展开与焦点反馈，少量客户端指针坐标增强图片景深。指针增强只在 fine pointer 且非 reduced-motion 时启用，requestAnimationFrame 合并写入并在卸载时清理。展开会改变列宽，仅在最多三张的独立排中执行，并在浏览器核对运动状态；其余动效只用 transform/opacity。
5. 手机和平板改为一列或两列完整摄影卡，不依赖 hover，不拦截首次点击。原生链接维持键盘 Enter、浏览器打开新标签等行为。无图片时保留清晰占位与文字。

## Risks / Trade-offs

- 宽度变化造成长标题重排 → 文字区限制最大宽度、折叠时保留名称和价格，展开呈现完整标题；键盘同等可达。
- 静态模板没有指针脚本 → 核心展开来自 CSS，无脚本仍有完整商品与入口。
- 列宽动画带来布局工作 → 限制每排数量、不做自动循环、检查实际展开状态；浏览器只读执行环境不开放 requestAnimationFrame，未完成帧间隔量测，不宣称跨设备 60fps。

## Migration Plan

先写规格与 UI 文档，再重构首页。保留此前其他页面改动，不激活外部店面。验证 SSR/模板、实际 hover/focus/click、手机、完整 check；无专用 smoke 进程时记录限制。
