首页现在是可手动滚动的商品 banner，桌面约两张、手机一张露出下一张；点击 banner 进入对应详情。banner 下方“查看更多”进入商品列表，随后是可切换的买家购买/店主上架四步介绍。列表可切换示例分页，详情可选择规格并复制示例需求。授权仅使用固定占位和“演示”按钮，不发送短信、请求真实 API 或创建账号、订单与付款。所有店名、地址、商品、价格、库存均为示例；图片为内联 SVG，不是生产素材。

## 买家怎样购买

1. 把正式站点 `/skill.md` 地址交给 Agent。
2. 说明想买的商品、预算等需求；Agent 查询公开商品和规格。
3. 需要下单时，按设备码地址在浏览器登录或注册，再批准 Agent。
4. 确认商品、规格和数量，在支付宝完成支付；让 Agent 查询订单，确认已支付。

## 店主怎样上架

1. 把正式站点的 `/merchant/skill.md` 地址交给自己的 Agent。
2. Agent 发起设备码授权，店主在浏览器用启动账号登录；首次登录改密后批准。
3. 向 Agent 说明商品名称、价格、库存、图片和属性。例如：“上架一款桌灯，售价 159 元，库存 24 件。”
4. Agent 选择目录，读取字段，创建商品和可售规格，上传封面，再调用 publish。
5. 必填字段和规格通过检查后才上架；失败时保持下架，由 Agent 读错误并补齐。上架成功后公开页才展示。

管理页只改密码，日常商品管理走 Agent。首页可切换两组分步指引，店主页保留上架说明。
