如何使用 MercLink

把 Skill 交给你的 Agent，在自己的浏览器里确认授权。

买家购买：四步开始

  1. 把 Skill 交给 Agent

    复制买家 Skill 地址，发给你的 Agent，让它了解查询和购买的方法。

    /skill.md

  2. 说出你的购买需求

    告诉 Agent 想买什么、预算多少，它会查询商品和可售规格。查商品无需登录。

    “找一款桌灯，预算 200 元。”

  3. 下单前登录并批准

    打开 Agent 给出的授权地址，在浏览器里用手机号验证或注册，并批准。密码和验证码留在浏览器里。

  4. 确认商品，完成付款

    确认规格和数量，再到支付宝收银台付款。付款后让 Agent 查询订单，确认已经支付。

店主管理：四步上架

  1. 把商家 Skill 交给 Agent

    复制商家 Skill 地址，发给你的 Agent，让它了解这家店的管理方法。

    /merchant/skill.md

  2. 店主登录并批准

    打开 Agent 给出的授权地址，用店主账号登录。首次登录先修改初始密码，再批准 Agent。

  3. 告诉 Agent 商品资料

    提供商品名、售价、库存、图片和属性；有颜色、尺码时，说明实际出售的组合。

    “上架这款桌灯，159 元，库存 24 件。”

  4. 检查资料，完成上架

    Agent 补齐字段和可售规格，上传封面，再上架。成功后，商品出现在店铺首页和商品列表。
