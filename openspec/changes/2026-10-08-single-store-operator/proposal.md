# 收成单店店主

## 为什么

公开面已经是一家店，但账号面仍要求超级管理员另开一个商家。单独部署时，这个开户步骤没有第二家店可管，只会挡住配置。

## 做什么

- 启动时确保恰好有一家店。店主就是环境变量创建的管理员，同一手机号、同一密码。
- 商家授权页用这个账号登录并批准 Agent。不再要求另开商家。
- 管理页只改密码。不再开通、停用或重置另一家商家。
- 商品、目录、令牌仍挂在商家行上。数据模型不拆掉租户边界。

## 不做什么

- 不合并买家账号。
- 不让 Agent 自助注册商家。
- 不把已有的第二家商家数据删掉。已有多家时不再自动新建，也不在这次改写他们的手机号。
