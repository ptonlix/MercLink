# Proposal

## Why

买家 Agent 必须按指定规格下一行订单，并只在支付宝确认后看到已支付。库存、幂等和支付状态如果散落到其他切片，并行实现时会重复扣库存或把支付字段写进订单头。

## What Changes

- 买家令牌创建只有一行的订单，服务端计算金额，并用业务单号幂等。
- 在一个事务内锁定可售规格、扣库存、写订单头、订单行和一条支付记录。
- 事务提交后向支付宝创建支付；通知验签后才把支付记录和订单头改为已支付。
- 查询仍为待支付的订单时向支付宝再查一次。超时关闭订单、支付记录并按行加回库存。
- 不实现退款、购物车、目录字段编辑或授权页。

## Capabilities

### New Capabilities

- `order-placement`: 单行下单、库存、幂等、订单查询权限和金额快照。
- `alipay-payment`: 支付记录、创建支付、验签通知、主动查单和超时关闭。

### Modified Capabilities

- 无。

## Impact

- 独占 `src/domain/commerce`、交易应用服务、支付宝适配器、`040_commerce.sql`、订单 API 和支付通知路由。
- 可售规格的锁定与库存回补只调用平台接缝，不导入目录模块内部函数。
- 支付私钥只出现在服务端适配器；Skill 文案不由本变更编写。
