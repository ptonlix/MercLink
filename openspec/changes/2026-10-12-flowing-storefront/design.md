## Context
用户明确要求先改文档再实现，覆盖上次禁止自动循环的决定。
## Goals / Non-Goals
完成十二项界面修正。不改变商品数据、购买流程或静态包协议。
## Decisions
- 使用 CSS 循环等宽商品组，视觉副本不重复进入键盘和读屏顺序。悬停/聚焦暂停，提供暂停控件；减少动态效果呈现静态列表。
- 原生 SVG 成都廊桥和熊猫，测量文字位置以跨字母爬行。简介完整 SSR，客户端叠层打字。
- 首页、列表、详情共享冷石墨令牌；页脚原生 details 展开现有使用说明和发现链接。
- 图集每张图片只渲染一次，原生 radio 配合左右切换控件；英文/中文用原生单选切换，未知字段完整保留。
- 静态源码包保留无脚本商品槽位与手动横向滚动，不伪造 React 动效。
## Risks / Trade-offs
- 持续动效影响阅读 → 悬停暂停、全局暂停和系统减少动态效果。
- 动画副本重复语义 → aria-hidden 与 tabIndex=-1。
- 图片失败或缺失 → 沿用占位；没有中文不编造翻译。
