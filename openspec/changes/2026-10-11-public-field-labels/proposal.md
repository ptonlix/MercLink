# 公开字段对人显示名称，对 Agent 保留键并注明含义

## 为什么

内置商品页和商品 Markdown 都直接展示字段键，例如 `origin`、`pearl_type`。这些键是给程序用的，给人看不友好。目录里已经有中文显示名，但公开缝在输出时丢掉了。

## 做什么

- 未激活店面时，给人看的商品页用字段显示名作为标题，例如「产地 / 北海合浦」。有显示名时，可见标题不再是键。
- `/products/{id}.md` 仍用键和值。每个有显示名的键在下一行注明 `含义：` 加上该显示名。
- 显示名来自同一次公开商品查询已经读到的活动字段定义，不另查一套商品内容。
- 公开商品 JSON 仍只在 `fields` 里放键和值。筛选和写入仍用键。
- 买家 Skill 说明商品 Markdown 会注明键的含义，并提醒不要把显示名当成字段键。
- 给人看的内置商品页不再单独展示商品 ID、目录 ID、整数分和原始可售状态。这些机器事实只写进商品 Markdown，并把整数分标成 `价格整数分：`。CNY 仍显示 `¥`；其他货币的主币价格仍带货币代码。

## 不做什么

- 不改公开 API 的 `fields` 形状，不把显示名写进 JSON-LD。
- 不改店面槽位 `field.key`。自定义页面若自己打印键，仍得到键。
- 不改规格轴的 `option_values` 展示。
- 不新增错误码、表或依赖。

## Capabilities

### New Capabilities

无。

### Modified Capabilities

- `public-pages`：给人看的商品页显示字段名称，不展示机器标识；商品 Markdown 保留键、注明含义，并包含机器标识。
- `agent-skills`：买家 Skill 说明商品 Markdown 中的键含义注释。

## Impact

公开商品缝、内置商品页、商品 Markdown 和买家 Skill。支付、授权和店面激活协议不变。
